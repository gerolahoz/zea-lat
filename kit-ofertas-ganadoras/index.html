Cómo instalarlo

01

Instalá Claude Code

Con una suscripción de Claude (Pro o Max), desde claude.com/claude-code o la app de escritorio, pestaña Code.

02

Copiá las skills

Descomprimí el .zip y copiá la carpeta skills a ~/.claude/skills/. O arrastrala a Claude Code y pedile que la instale.

03

Seguí el LEEME

Adentro del .zip está el paso a paso con los prompts listos para copiar y pegar.
